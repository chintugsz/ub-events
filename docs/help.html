Арга хэмжээ хаанаас ирдэг вэ?

Албан ёсны мэдээ, зохион байгуулагч, тасалбарын сайтаас өдөр бүр өглөө цуглуулна. Арга хэмжээ бүр эх холбоостой тул Эх мэдээллийг нээх дарж шалгаарай.

Мэдээлэл буруу байна

Цаг, газар, үнэ буруу эсвэл цуцлагдсан бол доорх холбоосоор мэдэгдээрэй. Арга хэмжээний нэрийг бичнэ үү.

Зохион байгуулагчдад

Арга хэмжээгээ нэмэхэд үнэгүй, бүртгэл хэрэггүй. Энэ маягтыг эсвэл апп доторх + товчийг ашиглана. Бид шалгаад нийтэлнэ, ихэвчлэн нэг өдрийн дотор.

Where do events come from?

Every morning they're gathered from official announcements, organizers and ticket sites. Every event links to where it was found: tap Open the listing to check it.

Something is wrong

If a time, place or price is wrong, or an event was cancelled, tell us with the link below and name the event.

For organizers

Listing an event is free and needs no account. Use this form or the + button in the app. We check every event before it goes live, usually within a day.
